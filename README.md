# Ingenio
Ingenio is a **GCSE maths revision website** with lessons, past papers, practice questions and an AI tutor. Ingenio is a work in progress

## Progress
### So far we've done:
* **Lessons tab** - Massive library of Powerpoints for any GCSE topic you require

* **Signup/login page** - Page where you can sign up or log in to Ingenio, with information saved to a database so you can continue right where you left off
