# Ingenio
Ace your maths exams for completely free!
An open source GCSE and A level mathematics revision site, built around the UK curriculum by students, for students, using PowerPoints, practice questions, personalised AI tutors, and past papers, all in one place :)

**Site:** https://daschdrioooo.github.io/Ingenio/hero/hero.html

Ingenio is built with HTML, CSS, and JS, and doesn't use frameworks. We might use a framework at some point.

> ! NOTE: Ingenio is currently a work in progress! Multiple things don't work yet.

## Features
- Clean UI (done)
- Authentication via Supabase (done)
- Lesson metadata creation (done)
- PowerPoint Slides (partially done)
- Dashboard (partially done)
- Onboarding (set up username, grades, target grades, topics)
- Practice question framework (partially done) - i.e seeded questions making them randomised

- AI tutor (not done)
- Revision timetable (not done)
- Themes (not done)
- Past papers (not done)
- Practice questions (not done)
- Google OAuth (not done)
- Better mobile layouts (not done)

## Running locally
1. Clone the repository:
`git clone https://github.com/daschdrioooo/Ingenio`
2. Move into the Ingenio directory
`cd Ingenio`
3. Use serve, or python http server to run:
`serve .` or `python3 -m http.server 8080`
